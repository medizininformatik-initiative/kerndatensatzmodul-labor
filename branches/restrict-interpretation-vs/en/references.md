# References

The Laboratory dataset refers to the [International Patient Summary](https://hl7.org/fhir/uv/ips/STU1.1/) and builds on the HL7 FHIR core specification, especially DiagnosticReport and Observation. Its content considers the German Medical Association's guideline on quality assurance in laboratory medicine (Rili-BÄK). The specification also draws on the MII core data set description of 10 March 2017 ([PDF](https://www.medizininformatik-initiative.de/sites/default/files/inline-files/MII_04_Kerndatensatz_1-0.pdf)) and the dataset description in ART-DECOR.
