# Search Parameters and Operations

The Simplifier guide generated separate interaction, search-parameter and operation tables with FQL. The IG Publisher renders the same normative REST requirements directly from the [MII Laboratory CapabilityStatement](CapabilityStatement-mii-cps-labor-capabilitystatement.md). That generated artifact page is authoritative and remains synchronized with the FSH source.

The current CapabilityStatement defines requirements for Observation, DiagnosticReport and ServiceRequest. It does not declare module-specific operations.
