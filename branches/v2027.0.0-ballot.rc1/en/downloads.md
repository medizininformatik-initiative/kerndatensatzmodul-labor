## Downloads

This page links the downloadable artifacts of this implementation guide.

### Package File

The package contains every value set, profile and extension of this version, together with the page list and the URLs, in the NPM format most FHIR tools read. It is the first choice for generating implementation artifacts, because it carries all the rules that make a profile valid. It does not replace reading the specification. See [validating profiles and resources](http://hl7.org/fhir/R4/validation.html) in the FHIR specification.

* [Package (compressed folder)](../package.tgz)

This guide is bilingual, and the publisher additionally produces one package per language, each carrying the designations of that language:

* [Package, English](../de.medizininformatikinitiative.kerndatensatz.labor.en.tgz)
* [Package, German](../de.medizininformatikinitiative.kerndatensatz.labor.de.tgz)
