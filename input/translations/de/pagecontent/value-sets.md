Zusätzlich zu den international verwendeten Terminologien definiert das Modul LABOR eigene ValueSets. Keines davon enthält eine Expansion — diese muss vor der Verwendung mittels eines Terminologieservers durchgeführt werden.

| ValueSet | Zweck |
|---|---|
| [Laborbereich](ValueSet-mii-vs-labor-laborbereich.html) | Laboruntersuchungen werden in diagnostische Fachbereiche gruppiert. |
| [Order Codes](ValueSet-mii-vs-labor-order-codes.html) | Kodierung der Beauftragungen von Laboruntersuchungen. |
| [Codierte Laborergebnisse](ValueSet-mii-vs-labor-laborergebnis-codiert.html) | Kodierte Laborergebnisse, umfasst qualitative und semiquantitative Ergebnisse. |
| [Qualitative Laborergebnisse](ValueSet-mii-vs-labor-laborergebnis-qualitativ.html) | Kodierung für qualitative Laborergebnisse. |
| [Semiquantitative Laborergebnisse](ValueSet-mii-vs-labor-laborergbenis-semiquantitativ.html) | Kodierung für semiquantitative Laborergebnisse. |
| [Interpretation](ValueSet-mii-vs-labor-interpretation.html) | Kategorische Bewertung eines Laborwertes; eingeschränkte Auswahl aus HL7 v3 ObservationInterpretation auf die im Laborkontext sinnvollen Konzepte. |
| [Interpretationsbeeinflussende Eigenschaften](ValueSet-mii-vs-labor-interpretation-eigenschaften-snomedct.html) | Codes zur Beschreibung von interpretationsbeeinflussenden Eigenschaften der Laboruntersuchung oder Probe. |
| [Quelle des klinischen Bezugsdatums](ValueSet-mii-vs-labor-quelle-klinisches-bezugsdatum.html) | Kodierung der Quelle des klinischen Bezugsdatums. |
| [Identifier-Typen](ValueSet-mii-vs-labor-identifier-type-codes.html) | Type-Codes, um zu bestimmen, welcher Identifier für einen bestimmten Zweck zu verwenden ist. |

Welche Codes für `Observation.interpretation` in Frage kommen und wie sich lokale Skalen darauf abbilden, ist in der [Interpretation](interpretation.html) erläutert.
